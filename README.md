# 💰 E-Wallet App

A secure Android digital wallet application designed for managing personal finances. The application allows users to monitor balances, manage transactions, and organize financial records through an intuitive interface.

## ✨ Features

- Wallet Balance
- Income Tracking
- Expense Tracking
- Transaction History
- Category Management
- Beautiful Dashboard
- Secure Data Storage
- Material Design UI

## 🛠️ Tech Stack

- Kotlin
- Android SDK
- XML
- Room Database
- RecyclerView
- MVVM
- LiveData
